- Project Overview - 
JS-02-SCHOOL-NETWORK adalah rancangan project  simulasi pembangunan infrastruktur jaringan komputer pada lingkungan sekolah menggunakan Cisco Packet Tracer. Project ini di kembangkan sebagai lanjutan dari pembelajaran dasar jaringan komputer dengan tujuan memahami bagaimana sebuah jaringan sekolah dirancang, dikonfigurasi, diamankan, dan dikelola secara terstruktur.

- Project Objectives -
Tujuan dari project ini adalah membangun simulasi jaringan sekolah dengan infrastruktur yang lebih kompleks dan mendekati penerapan jaringan di dunia nyata. Project ini juga bertujuan untuk meningkatkan pemahaman mengenai konfigurasi perangkat jariangan cisco, pengelolaan IP Address, routing, switching, keamanan jaringan, serta layanan jaringan internal.

- Network Architecture
Jaringan ini akan menggunakan beberapa perangkat utama, seperti router, multilayer switch, access switch, server, dan access point. jaringan antar gedung akan dihubungkan melalui perangkat pusat sehingga komunikasi antar bagian dapat berjalan secara terintegrasi.

segmentasi jaringan akan di terapkan menggunakan Virtual Local Area Network (VLAN), sedangkan komunikasi antar-VLAN dikelola melalui Inter-Vlan Routing. Selain itu, jaringan akan dirancang agar dapat terhubung ke internet melalui router ISP

- Network Services
Selain insfrastruktur jaringan, project ini juga akan mengimplementasikan beberapa layanan internal menggunakan server. Layanan tersebut meliputi Dynamic Host Configuration Protocol (DHCP) untuk memberikan konfigurasi IP Address secara otomatis kepada perangkat, Domain Name System (DNS) untuk menerjemahkan nama domain menjadi alamat IP, Web Server untuk menyediakan website internal sekolah, serta file server untuk mendukung peyimpanan dan pertukaran file. 

Website internal direncanakan memiliki beberapa layanan, seperti portal tempat belajar,e-learning, perpusnya sekolah yang dapat diakses melalui jaringann sekolah menggunakan nama domain internal.

- Network Security and Management
Keamanan jaringan menajadi salah satu aspek utama dalam pengembangan project ini. Penggunaan ACL akan diterapkan untuk mengatur komunikasi antar-VLAN berdasarkan kebutuhan masing-masing divisi. Port Security, DHCP Snooping, dan Dynamic ARP Inspection juga di rencanakan sebagai mekanisme perlindungan terhadap perangkat asing, DHCP ilegal, dan manupulasi ARP. 

Untuk mendukung pengelolaan jaringan, project ini juga akan menerapkan Syslog sebagain pencatatan aktivitas perangkat serta Network Time Protocol (NTP) untuk singkronasi waktu pada perangkat jaringan. 

- Testing dan Validation -

Setiap konfigurasi dan fitur yang di terapkan dan melalui tahapan pengujian untuk memastikan jaringan berjalan sesuai rancangan. Pengujuan meliputi konektivitas antar perangkat, komunikasi antar Vlan, Pembagian IP Address otomatis, akses domain internal, akses website, pembatasan hak akses, serta pengujian redudansi dan keamanan jaringan. 

Hasil akan di dokumentasikan sebagain bagian dari evaluasi keberhasilanimplementasi jaringan. 

- Expected Results - 
Hasil akhir yang diharapkan dari project ini adalah terciptanya simulasi infrastruktur jaringan sekolah yang terintegrasi, memiliki segmentasi jaringan yang terstruktur, layanan internal yang dapat digunakan, sistem keamanan yang memadai, serta mekanisme redudansi dan monitoring jaringan. 

Project ini diharapkan dapat menjadi sarana pembelajaran praktis sekaligus portofolio untuk menunjukan pemahaman dan kemampupan dasar hingga menengah dalam bidang Network Engineering
