# JS-01 - School Network

## 1. Project Overview

JS-01 School Network is a network infrastructure simulation project developed using Cisco Packet Tracer.

The project focuses on designing a computer network for a school environment consisting of two buildings.

## 2. Project Objectives

- Connect two school buildings.
- Implement VLAN segmentation.
- Configure inter-VLAN routing.
- Provide connectivity to the school server.
- Simulate internet connectivity through an ISP router.

## 3. Network Architecture

The network consists of:

- ISP Router
- School Router
- Core Switch
- Access Switches
- Server
- PCs
- Wireless Access Point

## 4. Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- Visual Studio Code
